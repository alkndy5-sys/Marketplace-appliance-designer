# ربط شركات GitHub Pages بالسحابة
1. أنشئ حسابًا ومشروعًا من https://supabase.com/dashboard . احتفظ بكلمة مرور قاعدة البيانات لنفسك.
2. افتح SQL Editor داخل مشروعك، وأنشئ استعلامًا جديدًا والصق محتوى supabase-brands.sql ثم اضغط Run. تُفصل بيانات المستخدمين بصلاحيات RLS.
3. من Connect أو إعدادات المشروع احصل على Project URL وPublishable key العام. لا تستخدم المفتاح السري.
4. حدّث index.html في جذر مستودع GitHub بالنسخة الموجودة في هذه الحزمة. عند فتح GitHub Pages اضغط ربط سحابة الشركات.
5. أدخل الرابط والمفتاح العام، ثم اضغط تنزيل إعدادات الربط. ارفع cloud-config.json إلى جذر مستودع GitHub؛ هذه إعدادات عامة فقط، ولا تحتوي كلمة مرور أو جلسة دخول.
6. في نافذة الربط أدخل بريدًا وكلمة مرور لحساب مكتبة الشركات، ثم أنشئ الحساب. فعّل بريدك إن طُلب ثم سجّل الدخول. هذا الحساب مخصص للمكتبة، ولا يلزم أن يكون كلمة مرور حساب GitHub أو Supabase الإداري.
7. من إدارة الماركات ارفع الشركات والشعارات أو استورد ملف JSON. راقب ظهور تم حفظ الماركات في حسابك. على الجهاز الآخر افتح رابط GitHub Pages وسجّل الدخول بحساب المكتبة نفسه.
إعدادات SQL لا تُرفع تلقائيًا ولا تُنفّذ بواسطة GitHub. البيانات الحالية على Sites لا تنتقل تلقائيًا إلى Supabase؛ استخدم تصدير واستيراد ملف الشركات من إدارة الماركات. ربط Supabase هنا خاص بمكتبة الشركات فقط، ولا يشغّل خدمات البحث عن الصور أو المواصفات السحابية الأخرى.

## الاتصال التلقائي
نُفذت ترقية public-brands.sql للمكتبة المشتركة: قراءة وإضافة عامة، تعديل وحذف لصاحب المكتبة. لا تحتوي الملفات على كلمة مرور أو مفتاح سري. أسماء الشركات وشعاراتها عامة، ويمكن لأي زائر إضافة شركة جديدة.
