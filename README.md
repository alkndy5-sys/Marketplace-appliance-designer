# مصمم مواصفات الأجهزة المنزلية

ملفات مصدر النسخة الحالية: استيراد إكسل، تصميم البوسترات، مطابقة المواصفات، 166 أيقونة، المواصفات المخصصة والترجمة، حفظ الماركات والمواصفات، والبحث عن الصور.

## الرفع إلى GitHub

1. أنشئ مستودعًا جديدًا.
2. فك ضغط الحزمة ثم ارفع محتويات المجلد عبر Add file → Upload files.
3. ارفع الملفات والمجلدات المخفية أيضًا، مثل .openai و.gitignore.
4. ارفع محتويات الحزمة وليس ZIP وحده ليصبح المصدر قابلًا للتعديل في GitHub.

## البناء والتحقق

يتطلب Node.js 22 أو أحدث؛ لا يحتاج تثبيت حزم npm.

    npm run build
    npm test

ناتج البناء: dist/server/index.js. ملف الواجهة app/index.html وحده لا يشغّل كامل البرنامج.

## الاستضافة

GitHub يحفظ المصدر. **GitHub Pages وحده لا يشغّل البحث والترجمة والحفظ الدائم** لأنها تتطلب خادمًا وقاعدة بيانات.

هذه النسخة مهيأة لمنصة Sites المبنية على Cloudflare Workers وقاعدة D1. ملف .openai/hosting.json يحتفظ بمعرّف الموقع الحالي. رفع الملفات إلى GitHub لا يحدّث الموقع الحالي تلقائيًا؛ يلزم إعداد بناء ونشر على استضافة تدعم الخادم.

للاستضافة الكاملة:

- ربط D1 باسم DB وتطبيق ملفات SQL في drizzle بالترتيب على قاعدة جديدة. لا تعِد إنشاء الجداول الموجودة في قاعدة الموقع الحالية.
- ضبط سر SEARCH_KEY_ENCRYPTION_KEY في إعدادات الاستضافة: 32 بايت عشوائية بصيغة Base64. لا تضع قيمته في GitHub. يجب الحفاظ على قيمته عند إعادة النشر لفك تشفير مفاتيح البحث الموجودة.
- يُدخل مفتاح Serper من إعدادات الموقع ويُحفظ مشفّرًا في حساب المستخدم. المتغير SERPER_API_KEY اختياري لمفتاح عام على الخادم.
- هوية المستخدم تأتي من الرأس الموثوق oai-authenticated-user-id الذي تضيفه Sites. النقل لاستضافة أخرى يحتاج نظام تسجيل دخول موثوقًا بديلًا؛ لا تثق بهذا الرأس إذا أرسله الزائر مباشرة.

## البيانات والأسرار

الحزمة لا تتضمن بيانات حسابك أو الماركات والمواصفات المحفوظة أو مفاتيح البحث أو سجل Git. مفاتيح الاختبارات وهمية.

تبقى البيانات في قاعدة الموقع الحالي عند تحديثه. نقلها إلى استضافة أو مشروع جديد يحتاج تصدير قاعدة D1 ونقل الأسرار بصورة منفصلة.

## هيكل الملفات

- app/index.html: الواجهة وتصميم البوسترات وتحليل المواصفات والأيقونات.
- app/vendor/xlsx.full.min.js: مكتبة إكسل المرفقة.
- worker/backend.js: خدمات البحث والترجمة والحفظ.
- drizzle/: مخطط قاعدة البيانات وترقياتها.
- build-images.cjs: بناء الخادم وتوليد توقيع روابط الصور.
- scripts/test.cjs وملفات test-*.cjs: اختبارات التشغيل.

## المكتبات الخارجية

مكتبة SheetJS المرفقة تحتفظ بإشعار حقوقها. تستخدم الواجهة مكتبات Lucide وTailwind CSS وhtml2canvas وJSZip عبر روابطها الأصلية. تحتاج اتصالًا بالشبكة لتحميلها وللبحث والترجمة. راجع THIRD_PARTY_NOTICES.md.
